What you can write to us about

  • Tool problems: links that won't open, an import that fails, or duplicate detection that looks wrong.
  • Broken pages: a blog post, menu link or page on this site that doesn't load properly.
  • Suggestions: changes that would save you time or make results clearer.
  • Questions: how a file format, limit or setting behaves.
  • Accessibility: trouble using the site with a keyboard, screen reader, zoom or high-contrast settings.

What to include in a problem report

  • What you expected to happen and what happened instead, including any message you saw.
  • How you added your URLs (pasted text, TXT, CSV, Excel or Word) and what you clicked next.
  • Your browser and device, if the issue could depend on them.
  • An example of a link or file layout that triggers it, with anything private removed.

The tool works in your browser, so we can't see the URLs or files you used. A clear description is the best way to help us reproduce the problem.

If only some links opened, check your browser's pop-up settings first. Browsers often block many tabs opened at once.
